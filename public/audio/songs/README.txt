SONG AUDIO FILES — CONFIGURATION GUIDE

Place your local MP3 audio files inside this folder using these exact filenames:
  1. public/audio/songs/my-love-mine-all-mine.mp3
  2. public/audio/songs/lady.mp3
  3. public/audio/songs/heather.mp3
  4. public/audio/songs/best-part.mp3
  5. public/audio/songs/midnight-sun.mp3
  6. public/audio/songs/come-over-and-love-me.mp3
  7. public/audio/songs/beige.mp3

If any file is not yet present, the game automatically falls back to a
procedural musical score for that song so every 3D experience remains playable.
